# Needed Theorems
## Fermat's Little Theorem
Not to be confused with Fermat's Last Theorem, Fermat's Little Theorem (FLT) states
{% quote silverman2012friendly %}
For $a,p \in\mathbb{N}$, if $p$ is prime and $p\not| a$ $\implies a^{p}\equiv a (\bmod p)$ 
{% endquote %}

## Euler's Totient Formula
Euler's totient function $\forall n\in\mathbb{N}$, denoted $\phi(n)$, is defined as the count of the natural numbers $x$, where $x < n$, such that $gcd(n,x) = 1$ (i.e., a count of the natural numbers less than $n$ that are *comprime* (or *relatively prime*) to $n$). There are some special cases of this function that are easy to calculate and that the RSA encryption algorithm leverage:

{% quote silverman2012friendly %}
For some $p\in\mathbb{N}$:
1. If $p$ is prime, then $\phi(p) = p-1$ (this actually makes sense if you think about for a few seconds!)
2. If $p$ is prime, and $k\in\mathbb{N}$, then $\phi(p^k) = p^{k}-p^{k-1}$
3. If $m\in \mathbb{N}$ is composite, with prime factorization $m = p_1^{e_1}\cdot p_2^{e_2}\cdots p_n^{e_n}$, then
$$\phi(m) = (p_1^{e_1} - p_1^{e_1 -1})(p_2^{e_2} - p_2^{e_2 -1})\cdots(p_n^{e_n} - p_n^{e_n -1})$$
4. For $m,n\in\mathbb{N}$ (prime or composite): $\phi(mn) = \phi(m)\phi(n)$
{% endquote %}

## Euler's Totient Theorem
Euler's Totient Theorem states {% cite silverman2012friendly %} that if $x,n \in \mathbb{N}$ are coprime (i.e., $gcd(x,n) = 1$), then

$$x^{\phi(n)} \equiv 1 (\bmod n)$$

## Euclidean Algorithm
The purpose of the Euclidean Algorithm is to find the *greatest common divisor* (GCD) between two numbers $m,n\in\mathbb{Z}$. The algorithm makes use of the following proposition:

{% quote Lauritzen2003 %}
Let $m,n\in\mathbb{Z}$. Then
- (i) $gcd(m,0) = m$ if $m\in\mathbb{N}$
- (ii) $gcd(m,n) = gcd(m-qn, n)$, for *every* $q\in\mathbb{Z}$  
{% endquote %}

In other words, this is saying that for some $d\in\mathbb{N}$, $d|m, d|n \iff d|(m-qn), d|n$ which implies 

$$gcd(m,n) = gcd(m-qn, n)$$

So, if we want to find the GCD between $m,n\in\mathbb{N}$ where $m \geq n \geq 0$ using Euclid's Algorithm we use the fact that $\exists q\in\mathbb{N}$ such that $m = qn + r \implies r = m-qn$, therefore $m \equiv r (\bmod n) \implies m = qn + r$ which means that

$$gcd(m,n) = gcd(r, n) = gcd(n,r)$$

And $n > r$. Repeating this process until we reach a remainder $r_n = 0$ means that $gcd(m,n) = r_{n-1}$. 

For example, we will calculate $gcd(131,1008)$:
> - $gcd(1008, 131) = gcd(1008 = 131q_1 + r_1, 131) = gcd(r_1 = 1008-131(7), 91) = gcd(r_1 = 91, 131)$
> - $gcd(131, 91) = gcd(131 = 91q_2 + r_2, 91) = gcd(r_2 = 131-91(1), 91) = gcd(r_2 = 40, 91)$
> - $gcd(91, 40) = gcd(91 = 40q_3 + r_3, 40) = gcd(r_3 = 91-40(2), 40) = gcd(r_3 = 11, 40)$
> - $gcd(40, 11) = gcd(40 = 11q_4 + r_4, 11) = gcd(r_4 = 40-11(3), 11) = gcd(r_4 = 7, 11)$
> - $gcd(11, 7) = gcd(11 = 7q_5 + r_5, 7) = gcd(r_5 = 11-7(1), 7) = gcd(r_5 = 4, 7)$
> - $gcd(7,4) = gcd(7 = 4q_6 + r_6, 4) = gcd(r_6 = 7-4(1), 4) = gcd(r_6 = 3, 4)$
> - $gcd(4,3) = gcd(4 = 3q_7 + r_7, 3) = gcd(r_7 = 4-3(1), 3) = gcd(r_7 = 1, 3)$
> - $gcd(3,1) = gcd(3 = 1q_8 + r_8, 3) = gcd(r_8 = 3-1(3), 3) = gcd(r_8 = 0, 4)$

So, $r_8=0 \implies r_{n-1 = 7} = 1$ (last non-zero remainder). Therefore, we can conclude that

$$gcd(131,1008) = 1$$

## Extended Euclidean Algorithm
The Extended Euclidean Algorithm (EEA) uses the quotients and remainders calculated at each iteration of the Euclidean Algorithm from the calculation of $gcd(m,n)$, for $m,n \in \mathbb{Z}$ to compute the **Bezout's Coefficients** that express the $gcd(m,n)$ as linear combination of $m,n$. That is, $\exists x,y \in\ mathbb{Z}$ such that

$$ mx + ny = gcd(m,n)$$

We can think of the EEA as working backwards through the steps of the Euclidean Algorithm using the linear combination we derived for each successive remainder. Looking back at our previous example and solving each for the respective remainder:

> - (i) $gcd(1008,131) = r_7 = 1 = 4(1) - 3(1)$
> - (ii) $r_6 = 3 = 7(1) - 4(1)$

Substituting (ii) into (i):

$$gcd(1008, 131) = 1 = 4(1) - 1[7(1) - 4(1)] = 4(2) - 7(1)$$

Repeating this process until we are left with a linear combination in terms of $131$ and $1008$ yields:

> - (iii) $r_5 = 4 = 11(1) - 7(1) \implies gcd(1008,131) = 1 = (2)[11(1)-7(1)] - 7(1) = 11(2) - 7(3)$
> - (iv) $r_4 = 7 = 40(1) - 11(3) \implies gcd(1008,131) = 1 = 11(2) - (3)[40(1) - 11(3)] = 11(11) - 40(3)$
> - (v) $r_3 = 11 = 91(1) - 40(2) \implies gcd(1008,131) = 1 = (11)[91(1) - 40(2)] - 40(3) = 91(11)-40(25)$
> - (vi) $r_2=40=131(1)-91(1)\implies gcd(1008,131) = 1 = 91(11) - (25)[131(1)-91(1)] = 91(36) - 131(25)$ 
> - (vii) $r_1=91=1008(1)-131(7) \implies gcd(1008,131)=1= (36)[1008(1)-131(7)] - 131(25)=1008(36)-131(277)$

So, the resultant linear combination is

$$gcd(1008,131) = 1 = 1008(36) + 131(-277)$$

So, the Bezout's Coefficients are $x = 36, y=-277$. For a GCD problem with more iterations, you would just repeat this process, iterating through all the remainders until we arrive back at the starting $m$ and $n$.

# Successive Squaring
This is useful process for computing large powers $x^k$ modulo $m$, by essentially converting the large exponent into binary-- more percisely, a sum of powers base 2. 

$$k = \sum_{i=0}^n b_i2^i = b_n2^n + \cdots + b_1 2^1+ b_2 2^0 = \sum_{i=0}^n b_i 2^i$$

Where $b_i\in\mathbb{N}$ is the $i^{th}$ bit in the binary representation of exponent $k$ and $n\in \mathbb{N}$ is the largest exponent such that $2^n \leq k$. 

For example, let's say we want to compute 

$$758^{731}(\bmod 1073)$$

Well, $731$ in binary is ```0b1011011011```, so it can be written as the 

$$731 = (1)2^9 + (0)2^8 + (1)2^7 + (1)2^6 + (0)2^5 + (1)2^4+ (1)2^3 + (0)2^2+ (1)2^2+(1)2^1+(1)2^0$$

To find this representation of exponent $k = 731$ without automatically knowing the binary representation, simply repeat the following algorithm

> 1. Find the largest power, $n$, of $2^n$ such that: $2^n \leq k$
> 2. Write $k$ as this $2^n$ plus a remainder, $r_n$: $k = 2^n + r_n$
> 3. Repeat this process at most $n-1$ times, finding the largest $2^t$ at each iteration $t$ such that $2^t \leq r_t$
> 4. When $r_t = 0$, stop.

For example, for our example $758^{731}(\bmod 1073)$:

> 1. $731 = 2^9 + 219$
> 2. $219 = 2^7 + 91$
> 3. $91 = 2^6 + 27$
> 4. $27 = 2^4 + 11$
> 5. $11 = 2^3 + 3$
> 6. $3 = 2^1 + 1$
> 7. $1 = 2^0 + 0$

Either way, we will arrive at the same summation:

$$731 = 2^9 + 2^7 + 2^6 + 2^4+ 2^3 + 2^1+ 2^0$$

This sum makes it easy to now rewrite our exponent $k = 731$ as

$$x^k = 758^{731} = 758^{2^9 + 2^7 + 2^6 + 2^4+ 2^3 + 2^1+ 2^0}$$

$$ = 758^{2^9}\cdot 758^{2^7}\cdot 758^{2^6}\cdot 758^{2^4}\cdot 758^{2^3}\cdot 758^{2^1}\cdot 758^{2^0}$$

Now for the "squaring" part in successive squaring: we can easily determine $x^{2^n} (\bmod m)$ by first computing $x^{2^0} = x^1 (\bmod m)$ and then repeatedly squaring the subsequent congruence, up to the largest power $2^n \leq k$. We are essentially just taking advantage of the Properties of Modular Arithmetic. Particularly, given that if $a \equiv b (\bmod m) \implies a^2 \equiv b^2 (\bmod m)$. This works in our favor by keeping the computations manageable. Suddenly, we don't need to calculate $758^{731} (\bmod 1073)$ outright, the biggest number we will need to compute is $1072^2 \equiv 1,149,184(\bmod 1073)$. This not only makes it easier and faster for a *computer* to calculate-- but it reduces the problem to something a human can do with a pen and paper (granted, it is still a pretty long problem, especially without a calculator)! For our example $758^{731}(\bmod 1073)$:

>0. $758^{2^0} \equiv 758^1 \equiv 758 (\bmod 1073)$
1. $758^{2^1} \equiv  758^2 \equiv 758^2 \equiv 574,564 \equiv 509 (\bmod 1073)$
2. $758^{2^2} \equiv  758^4 \equiv 509^2 \equiv 259,081 \equiv 488 (\bmod 1073)$
3. $758^{2^3} \equiv  758^8 \equiv 488^2 \equiv 1011 (\bmod 1073)$
4. $758^{2^4} \equiv  758^16 \equiv 1011^2 \equiv 625 (\bmod 1073)$
5. $758^{2^5} \equiv  758^32 \equiv 625^2 \equiv 53 (\bmod 1073)$
6. $758^{2^6} \equiv  758^64 \equiv 53^2 \equiv 663 (\bmod 1073)$
7. $758^{2^7} \equiv  758^128 \equiv 663^2 \equiv 712 (\bmod 1073)$
8. $758^{2^8} \equiv  758^256 \equiv 712^2 \equiv 488 (\bmod 1073)$
9. $758^{2^9} \equiv  758^512 \equiv 488^2 \equiv 1011 (\bmod 1073)$

Now, we can rewrite the original problem one more time:

$$ 758^{731} $$

$$ \equiv 758^{2^9}\cdot 758^{2^7}\cdot 758^{2^6}\cdot 758^{2^4}\cdot 758^{2^3}\cdot 758^{2^1}\cdot 758^{2^0}$$

$$ \equiv 758^{512}\cdot 758^{128}\cdot 758^{64}\cdot 758^{16}\cdot 758^{8}\cdot 758^{2}\cdot 758^{1}$$

$$\equiv 1011\cdot 712 \cdot 663 \cdot 625 \cdot 1011 \cdot 509 \cdot 758$$

And finally we have computed a solution to the original problem!
$$758^{731}\equiv 905 (\bmod 1073)$$

# The Basis of RSA: Computing the $k^{th}$ Root $(\bmod m)$
## Algorithm
Now that we have the Number Theory basis on Euclidean Algorithm, EEA, and successive squaring we have all the tools to start solving for $x$ in an expression like $x^k \equiv b (\bmod m)$. These types of problems are the basis for the RSA encryption.

$$x^k \equiv b (\bmod m)$$

1. First, in RSA, we pick prime $p, q\in\mathbb{N}$, and use these to define $m = pq$. This enables us to use Euler's Formula to easily calculate the totient:

$$\phi(m) = \phi(p)\phi(q) = (p-1)(q-1)$$

2. In RSA, we also pick the exponent $k$. This enables to force the applicability of Euler's Totient Function: If we choose an exponent $k$ that is coprime to $\phi(m)$, such that $gcd(\phi(m), k) = 1$,

$$x^{\phi(m)}\equiv 1 (\bmod m)$$

So, if we can use EEA to find Bezout's coefficients $(u_0,v_0)$ such that

$$ku_0 + \phi(m)v_0 = 1$$

With general solution

$$(u,v) = \Biggl\{ u_0+ \frac{\phi(m)}{gcd(\phi(m),k)}c, v_0 - \frac{k}{gcd(\phi(m), k)}c: \forall c\in\mathbb{Z}\Biggr\} $$

$$(u,v)= \Biggl\{u_0 + \phi(m)c, v_0 - kc: \forall c\in\mathbb{Z}\Biggr\}$$

We can easily find the smallest solution $(u,v) \in(\mathbb{N}\times\mathbb{N})$. Then, taking advantage of Euler's Totient Theorem:

$$(x^k)^u\equiv x^{ku}\equiv x^{1+\phi(m)v}\equiv x^1\cdot x^{\phi(m)v}\equiv x^1\cdot[x^{\phi(m)}]^v (\bmod m)$$

By Euler's Totient Theorem, if $gcd(x,\phi(m))=1$, then

$$x^{\phi(m)} \equiv 1 (\bmod m)$$

Note we will force $gcd(x,\phi(m))=1$ to be true using our choice of prime $p,q$, such that $m = pq$. We know $x < m$, so we simply need to make sure that $\phi(m) = (p-1)(q-1)> k$ when selecting $k$. This ensures a **unique** answer to our original problem, $x^k\equiv b(\bmod m)$, so that we can decrypt messages using the RSA method. So, by applying Euler's Totient Theorem we are left with:

$$(x^k)^u \equiv x^1\cdot[x^{\phi(m)}]^v \equiv x\cdot[1]^v \equiv x (\bmod m)$$

Or, in short,

$$(x^k)^u \equiv x(\bmod m)$$

Applying the original equivalence problem, $x^k\equiv b (\bmod)$, we can generate the new problem:

$$x \equiv b^u (\bmod m)$$

3. Now, that we have a problem in this form, we can solve for $x$ using successive squaring!

### Example: Computing the $k^th$ Root $(\bmod m)$
Let's return to the problem we were previously working on:

$$x^131 \equiv 758 (\bmod m)$$

Now, we have everything necessary to solve this problem!

1. Picking prime $p, q\in\mathbb{N}\implies m=pq$ and exponent $k$ such that $k$ and $\phi(m)=(p-1)(q-1)$ are coprime. In other words,

$$gcd(\phi(m), k) = 1$$

From our previous example, we have 

$$m = 1073 = 29\cdot 37$$

$$\phi(m) = (29-1)(37-1) = 1008$$

From the previous Euclid's Algorithm example we already verified that

$$gcd(\phi(m), k) = \gcd(1008, 131) = 1$$

So, we know that Euler's Totient Theorem will apply to subsequent steps in our problem!

2. Next, we are going to make use of Euler's Totient Theorem. Recall this theorem states that given $gcd(x,m)=1$, then $x^{\phi(m)} \equiv 1 (\bmod m)$. So, the point is that *if* we have $gcd(x,\phi(1073) = 1008) = 1$ then

$$x^{1008}\equiv 1 (\bmod m)$$

Let's rewrite $k = 131$ as a linear combination of $\phi(1073)=1008$$ in the form: 

$$ku = 1 +1008v$$

For some $v\in \mathbb{N}$. This will force Euler's Totient Theorem to be applicable: because $x^{1008}\equiv 1 (\bmod 1073)$ it will force $(x^u)^k\equiv x^1\cdot x^{1008} \equiv   x^1 \cdot 1\equiv x (\bmod 1073)$.

Like we already talked about, we can use the EEA to solve this piece of the puzzle. We need to find $(u,v)\in(\mathbb{N}\times\mathbb{N})$ such that

$$ku = 1 - mv$$

Where $k = 131$ (exponent from original problem) and $m = \phi(1073)=1008$. 

This is possible because $gcd(131,1008) = 1$. Now, in general, this may not always be true-- but, in the context of RSA encryption we get the freedom to **choose** our $k$! So, we can purposefully force this to be true!

So, the linear combination to find the Bezout's coefficients for is:

$$131u = 1 - 1008v$$

Earlier, when first discussing the EEA, we solved this problem and the Bezout's coefficients are:

$$(u,v) = (-277, 36)$$

Bezout's coefficients are not unique. Therefore, the general solution is:

$$(u,v) = \Biggl\{-277 + c\frac{1008}{1} , - 36 + c\frac{131}{1} \Biggr\}$$

For $\forall k\in\mathbb{Z}$. Therefore, for $c=1$ the smallest solution pair \[i.e., with $(u,v)\in(\mathbb{N}\times\mathbb{N})$\] is

$$(u,v) = (731,95)$$

Now, we have $131(731) = 1 + 1008(95)$. Substituting this back into Euler's Totient Theorem yields

$$x^{ku} \equiv x^{1+\phi(1073)v} (\bmod 1073)$$

$$x^{131\cdot 731} \equiv x^{1+1008v} \equiv x^1\cdot x^{1008\cdot95} \equiv x^1 \cdot (x^{1008})^95 \equiv x^1\cdot 1^{95}\equiv x (\bmod 1073)$$

In short, we are left with $(x^{131})^{731} \equiv x (\bmod 1073)$, which implies 

$$x \equiv 758^{731} (\bmod 1073)$$

So, now we have converted this problem into a problem we can solve via successive squaring. From earlier, we have already found this solution to this particular problem to be

$$x\equiv 905 (\bmod 1073)$$
