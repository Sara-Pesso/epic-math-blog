# Fermat's Little Theorem
Not to be confused with Fermat's Last Theorem, Fermat's Little Theorem (FLT) states
{% quote silverman2012friendly %}
For $a,p \in\mathbb{N}$, if $p$ is prime and $p\not| a$ $\implies a^{p}\equiv a (\bmod p)$ 
{% endquote %}

# Successive Squaring
This is useful process for computing large powers $x^k$ modulo $m$, by essentially converting the large exponent into binary-- more percisely, a sum of powers base 2. 

$$k = \sum_{i=0}^n b_i2^i = b_n2^n + \cdots + b_1 2^1+ b_2 2^0 = \sum_{i=0}^n b_i 2^i$$

Where $b_i\in\mathbb{N}$ is the $i^{th}$ bit in the binary representation of exponent $k$ and $n\in \mathbb{N}$ is the largest exponent such that $2^n \leq k$. 

For example, let's say we want to compute 

$$758^{731}(\bmod 1073)$$

Well, $731$ in binary is ```0b1011011011```, so it can be written as the 

$$731 = (1)2^9 + (0)2^8 + (1)2^7 + (1)2^6 + (0)2^5 + (1)2^4+ (1)2^3 + (0)2^2+ (1)2^2+(1)2^1+(1)2^0$$

To find this representation of exponent $k = 731$ without automatically knowing the binary representation, simply repeat the following algorithm

> 1. Find the largest power, $n$, of $2^n$ such that: $2^n \leq k$
2. Write $k$ as this $2^n$ plus a remainder, $r_n$: $k = 2^n + r_n$
3. Repeat this process at most $n-1$ times, finding the largest $2^t$ at each iteration $t$ such that $2^t \leq r_t$
4. When $r_t = 0$, stop.

For example, for our example $758^{731}(\bmod 1073)$:

> 1. $731 = 2^9 + 219$
2. $219 = 2^7 + 91$
3. $91 = 2^6 + 27$
4. $27 = 2^4 + 11$
5. $11 = 2^3 + 3$
6. $3 = 2^1 + 1$
7. $1 = 2^0 + 0$

Either way, we will arrive at the same summation:

$$731 = 2^9 + 2^7 + 2^6 + 2^4+ 2^3 + 2^1+ 2^0$$

This sum makes it easy to now rewrite our exponent $k = 731$ as

$$x^k = 758^{731} = 758^{2^9 + 2^7 + 2^6 + 2^4+ 2^3 + 2^1+ 2^0}$$

$$ = 758^{2^9}\cdot 758^{2^7}\cdot 758^{2^6}\cdot 758^{2^4}\cdot 758^{2^3}\cdot 758^{2^1}\cdot 758^{2^0}$$

Now for the "squaring" part in successive squaring: we can easily determine $x^{2^n} (\bmod m)$ by first computing $x^{2^0} = x^1 (\bmod m)$ and then repeatedly squaring the subsequent congruence, up to the largest power $2^n \leq k$. We are essentially just taking advantage of the Properties of Modular Arithmetic. Particularly, given that if $a \equiv b (\bmod m) \implies a^2 \equiv b^2 (\bmod m)$. This works in our favor by keeping the computations manageable. Suddenly, we don't need to calculate $758^{731} (\bmod 1073)$ outright, the biggest number we will need to compute is $1072^2 \equiv 1,149,184(\bmod 1073)$. This not only makes it easier and faster for a *computer* to calculate-- but it reduces the problem to something a human can do with a pen and paper (granted, it is still a pretty long problem, especially without a calculator)! For our example $758^{731}(\bmod 1073)$:

>0. $758^{2^0} \equiv 758^1 \equiv 758 (\bmod 1073)$
1. $758^{2^1} \equiv  758^2 \equiv 758^2 \equiv 574,564 \equiv 509 (\bmod 1073)$
2. $758^{2^2} \equiv  758^4 \equiv 509^2 \equiv 259,081 \equiv 488 (\bmod 1073)$
3. $758^{2^3} \equiv  758^8 \equiv 488^2 \equiv 1011 (\bmod 1073)$
4. $758^{2^4} \equiv  758^16 \equiv 1011^2 \equiv 625 (\bmod 1073)$
5. $758^{2^5} \equiv  758^32 \equiv 625^2 \equiv 53 (\bmod 1073)$
6. $758^{2^6} \equiv  758^64 \equiv 53^2 \equiv 663 (\bmod 1073)$
7. $758^{2^7} \equiv  758^128 \equiv 663^2 \equiv 712 (\bmod 1073)$
8. $758^{2^8} \equiv  758^256 \equiv 712^2 \equiv 488 (\bmod 1073)$
9. $758^{2^9} \equiv  758^512 \equiv 488^2 \equiv 1011 (\bmod 1073)$

Now, we can rewrite the original problem one more time:

$$ 758^{731} $$

$$ \equiv 758^{2^9}\cdot 758^{2^7}\cdot 758^{2^6}\cdot 758^{2^4}\cdot 758^{2^3}\cdot 758^{2^1}\cdot 758^{2^0}$$

$$ \equiv 758^{512}\cdot 758^{128}\cdot 758^{64}\cdot 758^{16}\cdot 758^{8}\cdot 758^{2}\cdot 758^{1}$$

$$\equiv 1011\cdot 712 \cdot 663 \cdot 625 \cdot 1011 \cdot 509 \cdot 758$$

And finally we have computed a solution to the original problem!
$$758^{731}\equiv 905 (\bmod 1073)$$

```python
# 2. Successive Squaring
def successive_squaring(a, k, m):
    exps = []
    while k > 0: 
        j = 0 
        while 2**(j+1) < k:
            j += 1

        exps.append(j)
        k = k - 2**j

    # print(exps)
    mod_m = [a % m]
    for j in range(1, exps[0] + 1):
        mod_m.append(mod_m[j - 1]**2 % m)

    b = 1
    for i in range(0, len(exps)):
        b = b*mod_m[exps[i]] % m
    return b
```
