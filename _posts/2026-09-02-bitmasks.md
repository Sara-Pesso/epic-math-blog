## Bitmask Basics. 
Let's kick this off with an example. Let's say you have $n$ light bulbs and you want to describe their *state* (that is, whether each light bulb is currently on or off). If we have $n=3$ lightbulbs, 
$$110$$
Would represent light bulbs 0 and 1 being turned on (first two digits set to "1"), where lightbulb 2 is turned off (last digit set to zero). Observe further that we can convert this sequence of ones and zeroes to base 10 number:
$$2^2 = 4$$
$$2^1 = 2$$
$$2^0 = 1$$
Because only the first two lightbulbs are on, 
$$4*1 + 2*1 + 1*0 = 6$$
Will represent the lightbulbs in this state. If we were to flip the final lightbulb on we'd have $$4*1+2*1+1*1 = 7$$. Because we are using the individual digits in binary to represent each individual lightbulb, for $n$ lightbulbs, we'd need a $n$ digit long binary number to represent our state. Then, depending on the index, $i$, of each lightbulb, the expression
$$m*2^i$$
where $m$ represents a 1 for an on lightbulb and 0 an off lightbulb, is associated with the individual lightbulb. 

## A Guide to Bitmask Operators (in Python)
Python has some pretty nice operators for manipulating the bits in our bitmask. They are:

- Left Shift: $<< i$
    - Shift bits left $i$ binary digits (equivalent to adding $2^i$ in base 10).
    - Example: 3 << 2 = 12
        - This shifts the bits of 3 (in binary, 11) to the left two digits. In binary, this is 1100, or 12. 
    - If we want to set only the $i^th$ digit in our mask to 1 (i.e., turn lightbulb $i$ "on"),
    ```python
    m = (1 << i)
    ``` 
- Right Shift: $ >> i$
    - Shifts bits right $i$ digits (see examples above)
- OR: $|$
    - Used to set bits
    - Example: Below, we can see that 19 in binary is 10011, and 12 is 110. We tell Python to set the binary digits of 10011 to "1" if they are a "1" in 110. This leaves 11111, or 31.  
    ```python
    m = 19
    m |= 12
    print(m)
    # Output: 31
    ```
    - Another way to use this is by using the left shift operators ($>>$) to define which bit to set
    ```python
    m = 18
    m |= (1 << 2)
    print(m)
    # Output 22
    ```
- AND: $\&$
    - Check if the same bits are set in two masks
    - Example: 13 & 7 = 5
        - In binary, 13 is 1101 and 7 is 0111. These have the $2^2$ and $2^0$ bits in common (both set to 1). In base 10, this is 5.
    - In binary 19 is 10011 and 22 is 10110. We can see they have bits $i = 1, 4$ in common. This means, $2^4 + 2^1 = 18$ is our result. 
    ```python
    m = 19
    ask = 22
    print(m&ask)
    # Output: 18
    ```
- XOR: ^
    - Toggles bits (switch from 1 to 0 or vis versa). Can also be used to determine which bits between two binary numbers are different.
    - Examples: Below, in binary 19 is 10011 and 22 is 10110. When we compare the bits, the only ones that are different are bits $i = 0, 2$. So, it outputs $2^2+2^0 = 5$
    ```python
    m = 19
    ask = 22
    print(m^ask)
    #Output: 5
    ```
    - Or, we can use it to the toggle the $i^{th}$ bit. Again, 19 is 10011, if we want to switch lightbulb $i=3$ "on", we will have 11011 or 27.
    ```python
    m = 19
    m ^= (1 << 3)
    print(m)
    #Output: 27
    ```
- NOT: ~
    - Flips the $i^{th}$ bit. 
    - Example: When used in conjunction with the AND ($\&$) operator, we cna easily set the third bit of 27 (11011) to 0 (that is, turn off lightbulb number 3), leaving us 10011. This is equivalent to $27 - 2^3 = 27-8 = 19$. 
    ```python
    m = 27
    m &= ~(1 << 3)
    print(m)
    # Output: 19
    ```

## Using Bitmasks to Assign Objects
Let's say with have $n$ objects that need to be assigned to $n$ people, and each object costs a different amount to assign to each person. How can we find the minimum cost to assign each person one of the objects?

For this we we will use a tabulation approach. Given a cost matrix in the form

$$C = \begin{bmatrix}
c_{11}&c_{12}&\cdots&c_{1n}\\
c_{21}&c_{22}&\cdots&c_{2n}\\
\vdots & \vdots& \ddots&\vdots\\
c_{n1}&c_{n2}&\cdots&c_{nn}\\
\end{bmatrix}$$

where each $c_{ji}$ represents the cost of assigning object $i$ to person $j$, we can use the following pseudocode to initialize our DP solution:
1. Determine the total number of states (including non-solution subproblems!)
    - We will do this using a bitmask. Each person will represent one bit in our mask. This will represent the subset of people assigned an object. So, we will need to work through $2^n$ states:
    ```python
    nstates = 1 << n
    ```
2. Initialize the DP table, filling in the minimum cost at each intermediate state with infinity
```python   
dp = [inf] * nstates
```
3. Basis: because assigning 0 objects to 0 people will always cost nothing:
```python
dp[0] = 0
```

Once the DP table has been initialized, we are ready to apply our tabulation solution:
4. Iterate through all the possible bitmasks (that is, subsets of people assigned an object)
    - Determine which object we are about to assign to someone. This can be determined by determining how many bits in our bitmask have already been set. 
    ```python
    obj_i = bin(mask).count('1')
    if obj_i == n:
        continue
    ```
    - Because we are iterating from $0$, if $obj_id = n$, we have already assigned all the objects to a person and we continue out of the loop.

5. Try to assign object $i$ to any available person, $j$, by looping through the $n$ bits in the $mask$ and determining if they haven't yet been assigned an object. We can do this by using the AND ($\&$) operator to determine if bit $j$ is unset (i.e, if bit $j = 0$):
    ```python
    for j in range(n):
        if (mask & (1 << j)) == 0:
    ```
    - If bit $j=0$, we assign object $i$ to bit j using the OR (|) operator. Then, we calculate the cost make that assign which is as simple as finding element $(j,i)$ in our cost matrix and adding it to the *current* cost held for the current mask in our DP table:
    ```python
        new_mask = mask | (1 << j)
        new_cost = dp[mask] + cost[j][i]
    ``` 
    - Because we are looking for the *minimum* cost of assigning all $n$ objects, we only accept the new cost derived from assign object $i$ to person $j$ with respect to the *new* mask if our *new* cost is less than whatever is *currently* held in the DP table for the *new* mask.
    ```python
        if new_cost < dp[new_mask]:
            dp[new_mask] = new_cost
    ```
    - It may seem a little odd at first that there would be anything in $DP(new_mask)$, since we seem to be looping through the bitmasks in numeric order. Seemingly, the value of this $new_mask$ should be $\inf$ at first thought. But, remember that we are in a double nested loop. Before we start looping through each person $j$ to determine if they already have an object, we first are looping through each bitmask (or really through each object), $i$. So, it is very possible -- unless we are on object $i = 0$ --  that our callstack has already evaluated some other permutations of item assignments for $new_mask$.
    - Ultimately, because this a tabulation solution, once our program has looped through all bitmasks, the final entry in our DP table, $DP((1 << n) - 1)$ -- that is, the bitmask that contains all 1s -- will hold the minimum cost to assign $n$ objects to $n$ people. 
    ```python
    return dp[(1 << n) - 1]
    ```

## Retrieving the Optimal Assignment from the DP Table
Now, knowing the minimum cost of assignment is only so useful. We probably also want to know what object $i$, for $0 < i < n$, is assigned for each person $j$ for $0 < j < n$. This is a pretty simple addition in this case!

All that needs to be done is that every time we update our newly found minimum cost for each bitmask, we also keep track of the old mask we just came from and the newly assigned person $j$. This way, we can work backwards from the "final mask" (i.e., the bitmask of all 1s) and figure out which bitmask containing only only one 0 (one unassigned person) gives that minimum final solution, and then which bitmask with two 0s (2 unassigned people) leads to the minimum cost for the bitmask with one 0, and so on and so forth until we reach the basis. 

This looks like initializing a Python dictionary that maps our *new mask* to a tuple of the *previous mask* and *person $j$* around the same time we initialize our DP table:
```python
    previous_assignment = {}
```
Then, every time we find a new current minimum cost in our search, we update the previous assignment table at the same time as the DP table. This keeps track of where the minimum solution "came from".
```python
previous_assignment[new_mask] = (current_mask, j)
```
Extracting the final optimal assignments is then pretty straight forward. 
We initialize an empty list to hold the assignments where the list's index j
corresponds to person j. Then, we simply loop *backward* through each person 
n > j > 0 (since person n was assigned last). Each iteration we find the 
previous bitmask and object assigned for each current bitmask, assign person j
to that object, and loop again using the previous bitmask as the current mask:
```python
    n = len(costs)
    assignments = [-1] * n
    curr_mask = (1 << n) - 1

    for obj in range(n - 1, -1, -1):
        prev_mask, node = previous_assignment[curr_mask]
        assignments[node] = obj
        curr_mask = prev_mask
    return dp[(1 << n) - 1], assignments
```
(Note: this does not change the time or space complexity.)

```python
from math import inf
def assignment(cost):
    # Number of things to be assigned 
    n = len(cost)

    # 1. We will do this using a bitmask. 
    # Each node will represent one bit in our mask. 
    # This will represent the subset of people assigned an object. 
    # So, we will need to work through 2^n states
    nstates = 1 << n
    
    # 2. Initialize the DP table, filling in the minimum cost at each intermediate state with infinity
    dp = [inf] * nstates
    
    # 3. Basis: because assigning 0 objects to 0 people will always cost nothing
    dp[0] = 0 

    # 3.5. Initializing a Python dictionary that maps our *new mask* to a tuple of 
    # the *previous mask* and *node j* (for extracting the assignment solution later)
    previous_assignment = {}

    # ---- Begin Tabulation & Bitmasking ----
    # 4. Iterate through all the possible bitmasks (that is, subsets of people assigned an object)
    for mask in range(nstates):
        # Determine which object we are about to assign to someone. This can be determined by determining how many bits in our bitmask have already been set.
        obj_idx = bin(mask).count('1')
        
        # Because we are iterating from 0, if obj_id = n$ we have already assigned all the objects to a node and we continue out of the loop.
        if obj_idx == n:
            continue
            
        # 5. Try to assign object i to any available node, j, by looping through 
        # the n bits in the mask and determining if they haven't yet been assigned 
        # an object. We can do this by using the AND (&) operator to determine if 
        # bit j is unset (i.e, if bit j = 0):
        for j in range(n):
            # If bit j=0, we assign object $i$ to bit j using the OR (|) operator. Then, we 
            # calculate the cost make that assign which is as simple as finding element (j,i) 
            # in our cost matrix and adding it to the *current* cost held for the current mask 
            # in our DP table:
            if (mask & (1 << j)) == 0:
                new_mask = mask | (1 << j)
                new_cost = dp[mask] + cost[j][obj_idx]
                
                # Because we are looking for the *minimum* cost of assigning all n 
                # objects, we only accept the new cost derived from assign object i 
                # to node j with respect to the *new* mask if our *new* 
                # cost is less than whatever is *currently* held in the DP table for 
                # the *new* mask.
                if new_cost < dp[new_mask]:
                    dp[new_mask] = new_cost
                    # every time we find a new current minimum cost in our search, we update the previous 
                    # assignment table at the same time as the DP table. This keeps track of where the minimum solution "came from".
                    previous_assignment[new_mask] = (mask, j)
                    
    # Ultimately, because this a tabulation solution, once our program has 
    # looped through all bitmasks, the final entry in our DP table, 
    # DP((1 << n) - 1) -- that is, the bitmask that contains all 1s -- will hold the minimum cost to assign n objects to n people. 
    
    # --- Extracting Assignments from the DP Table ----
    # Extracting the final optimal assignments is then pretty straight forward. 
    # We initialize an empty list to hold the assignments where the list's index j
    # corresponds to node j. Then, we simply loop *backward* through each node 
    # n > j > 0 (since node n was assigned last). Each iteration we find the 
    # previous bitmask and object assigned for each current bitmask, assign node j
    # to that object, and loop again using the previous bitmask as the current mask:
    n = len(costs)
    assignments = [-1] * n
    curr_mask = (1 << n) - 1

    for obj in range(n - 1, -1, -1):
        prev_mask, node = previous_assignment[curr_mask]
        assignments[node] = obj
        curr_mask = prev_mask
    return dp[(1 << n) - 1], assignments

## ---- MAIN ----
# Example Usage:
# 3 people (rows), 3 objs (columns) cost matrix
# Where each c_{ji} represents the cost of assigning object i to node j
costs = [
    [3,4,7],
    [11,15,8],
    [9,4,6]
]

## ---- RESULTS ----
min_cost, assignments = assignment(costs)
for i in range(len(assignments)):
    print(f"Node {i} -> Object {assignments[i]}: Cost {costs[i][assignments[i]]}")
print("Min. Cost:", min_cost)
```

## In Terms of Time & Space Complexity
And there you have it: a simple example on how to integrate bitmasking into your dynamic programming solutions to make them more efficient and manageable! If we were to just brute force our way through every possible permutation of object assignments, the time complexity is $O(n!)$. Of course, the space complexity is just $O(1)$ since we are only keeping track of one number: the current minimum cost.

But, when we apply a dynamic tabulation approach, because we are looping through all the possible masks (of which there are $2^n$) and then looping through each person (of which there are $n$), the time complexity is $O(n*2^n)$. Similarly, because there are $2^n$ bitmasks we're evaluating and therefore our DP table is that size, the space complexity is $O(2^n)$. 

In terms of time complexity, DP with bitmasking is an appropriate solution to this problem for $n \leq 20$. After that, a better approach would be [The Hungarian Algorithm for assignment problems](https://cp-algorithms.com/graph/hungarian-algorithm.html#the-mathcalon3-algorithm) which can reduce time complexity to $O(n^3)$, but until $n=20$ it's still a fairly fast solution. We won't be discussing the Hungarian Algorithm here, but it has potential to be another blog post; so stay tuned!
